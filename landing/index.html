Government filing desks. University intranets. 15-year-old ERPs. No API, and never will be.

When there is no API, the browser is the API.

A compact index, not the raw page.

We never send the HTML to the model — we send a short list of the elements that matter.

01

Index

The page becomes a list of at most 150 elements, each with a stable reference.

02

Reason

The agent proposes a value for each field, citing its reasoning.

03

Approve

A person reviews and approves before anything is written.

One agent, three flows.

Assisted form filling live

Extracts data from a pasted email, maps it to the form on screen, proposes it field by field.

Table reading later

Answers questions about a case tray extracted from the page.

Pre-submission review later

Flags empty fields and inconsistencies before the system rejects them.

The agent never submits.

It reads, it proposes, it writes fields after approval — but a person presses submit. The submit tool isn't disabled. It isn't implemented.
